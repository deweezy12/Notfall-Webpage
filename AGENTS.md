# AI Agent Guide

This repository contains only the active Spacefield Media website. Read this file before changing the project.

## Source Of Truth

- `site/` is the authoritative website.
- `dist/` is generated by `pnpm build`; never edit or commit it.
- `scripts/` contains the dependency-free build and validation tools.
- The website is deployed from GitHub Actions to GitHub Pages.
- There are intentionally no legacy websites or `/archive/` routes.

## Important Constraint

The application in `site/assets/` is a prebuilt bundle recovered without its original React source. Treat the hashed JavaScript and CSS as vendored compiled output. Prefer small, verified changes. For a major redesign or architectural feature, recreate a normal source application rather than layering more fragile string patches onto the bundle.

## Public Routes

- `/`
- `/projects/`
- `/services/`
- `/contacts/`

Do not reintroduce `/archive/`, `/spacefield/`, or `/spacefieldmedia2/` paths.

## Commands

```sh
pnpm dev
pnpm build
pnpm check
pnpm serve
```

Run `pnpm build && pnpm check` after every website change. Use `PORT=4173 pnpm serve` when a production preview is needed.

## Editing Rules

- Keep root-relative URLs because the production site uses a custom domain.
- Keep `site/CNAME` and `site/.nojekyll` at the website root.
- Add project images under `site/projects/`.
- Keep metadata in all four HTML files accurate and in German.
- Update `scripts/check.mjs` if required routes or hashed asset names change.
- Do not add dependencies for tasks that Node.js can handle directly.
- Do not commit generated `dist/`, dependency folders, operating-system files, or raw media originals.

## Completion Checklist

1. Build succeeds with `pnpm build`.
2. Validation succeeds with `pnpm check`.
3. `/`, `/projects/`, `/services/`, and `/contacts/` load directly.
4. JavaScript, CSS, favicon, and project images resolve from root paths.
5. No removed legacy or archive paths are referenced.
