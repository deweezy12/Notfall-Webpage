# Nagelstudio Website Improvements

This document lists recommended improvements for the Nagelstudio website from a senior web design and conversion perspective. The goal is to make the page feel more premium, more trustworthy, easier to scan, and better at turning visitors into bookings.

## 1. Hero Section

The hero should immediately communicate what the studio offers and why the visitor should book.

Recommended changes:

- Use one strong real nail or studio image as the main visual.
- Keep the booking CTA visible above the fold.
- Tighten the headline and supporting copy.
- Improve text contrast over the hero image.
- Keep the first screen focused on booking, not general explanation.

Example direction:

```text
Nageldesign, Manikuere & Pedikuere
Gepflegte Naegel in entspannter Atmosphaere.
```

## 2. Gallery Carousel

The gallery is one of the strongest trust signals because visitors want to see real results. The carousel is a better layout than an uneven grid.

Recommended next improvements:

- Show a small part of the next image so visitors understand it scrolls.
- Add subtle left and right arrow buttons.
- Add dots or a slim progress indicator below the carousel.
- Keep mouse drag support.
- Add keyboard navigation for accessibility.
- Snap the carousel neatly to cards after dragging.
- Keep the current square image size and hover overlay style.

## 3. Leistungen & Preise

The pricing section is now more symmetrical, but it can become more premium and easier to compare.

Recommended changes:

- Highlight one popular service with a small "Beliebt" badge.
- Make prices visually stronger.
- Add small category icons or minimal symbols for Manikuere, Pedikuere, Design, and Extras.
- Keep dividers between individual services.
- Add a CTA below the section: "Termin fuer diese Leistung buchen".
- Keep the four-card desktop layout and two-by-two tablet layout.

## 4. Booking Section

The booking section is the main conversion point and should feel more important.

Recommended changes:

- Add a compact three-step row:
  1. Leistung auswaehlen
  2. Termin buchen
  3. Bestaetigung erhalten
- Add a WhatsApp or email fallback next to the Google Calendar button.
- Make the booking card visually stronger than surrounding text.
- Repeat the booking CTA after the gallery or reviews.
- Mention that the consultation is free if that is accurate.

## 5. Visual Design System

The current pink/nude direction works for the industry, but it should be refined into a clearer visual system.

Recommended changes:

- Use one primary accent color consistently.
- Use one soft background tint for calm sections.
- Use one dark text color for readability.
- Standardize border radius, shadows, and spacing.
- Avoid making every section feel like a card.
- Keep the page elegant, warm, and clean.

## 6. Typography

The typography should feel refined and easy to scan.

Recommended changes:

- Make section headings slightly calmer and more elegant.
- Keep hero typography strong, but avoid oversized text inside compact sections.
- Improve line-height in longer paragraphs.
- Keep body text shorter and more direct.
- Use consistent heading sizes across sections.

## 7. Page Flow

The page should guide visitors from interest to proof to booking.

Recommended order:

1. Hero
2. About / value promise
3. Leistungen & Preise
4. Unsere Arbeiten carousel
5. Reviews
6. Booking
7. Contact

The booking CTA can appear multiple times, but the full booking section should appear after enough trust has been built.

## 8. Reviews Section

Reviews can feel more credible with stronger visual structure.

Recommended changes:

- Add initials or small avatar circles.
- Show a rating summary like "5.0 / 5.0".
- Keep review cards equal height.
- Add source context if reviews are from Google or another platform.
- Reduce overly generic text if real reviews become available.

## 9. Contact Section

The contact area should be easy to scan and action-oriented.

Recommended changes:

- Split address, phone, email, and opening hours into compact blocks.
- Add a "Route planen" button.
- Make WhatsApp prominent if it is used for bookings.
- Reduce map height on mobile.
- Keep the most important contact options visible without scrolling too much.

## 10. Mobile Experience

Most visitors may arrive on mobile, so the mobile version needs special attention.

Recommended changes:

- Add a simple mobile menu or sticky bottom CTA.
- Keep "Buchen", "Preise", and "Kontakt" easy to access.
- Make carousel cards easy to swipe.
- Ensure buttons do not wrap awkwardly.
- Keep section spacing tighter on small screens.

## 11. Microinteractions

Small interactions can make the site feel more polished.

Recommended changes:

- Add smooth but subtle hover states.
- Keep image zoom restrained.
- Use clear carousel drag cursor states.
- Add button press states.
- Highlight the active navigation section while scrolling.
- Respect reduced-motion preferences.

## 12. SEO And Content

The page should support local search and service-specific searches.

Recommended changes:

- Add location to key SEO text once the real city is known.
- Add short service-specific text for Manikuere, Pedikuere, Gel-Naegel, and Nail Art.
- Add an FAQ section for common booking questions.
- Include expected duration and pricing context.
- Use descriptive image alt text for gallery images.

Useful FAQ topics:

- Wie lange dauert eine Manikuere?
- Was kostet Gel-Lack?
- Kann ich Designs vorab zeigen?
- Wie funktioniert die Terminbuchung?
- Was passiert bei einer Stornierung?

## Recommended Next Steps

Highest priority:

1. Add gallery carousel arrows and progress indicator.
2. Improve the booking section visually and structurally.
3. Add a stronger mobile booking CTA.
4. Refine the reviews section for credibility.
5. Add a small FAQ section for SEO and visitor confidence.
